# private/

調査用の機密データと、公開できない証跡の置き場。**このREADME以外はGit管理外。**

`docs/` は全て公開可能であることを前提に運用する。**公開できないものは全てここへ置き、`docs/` からはパスで参照する。**

## 置くもの

**国会会議録APIから取得したデータは機密データとして扱う**（`CLAUDE.md` 3章）。出典が公開情報であることを理由に緩めない。
顧客アンケートの自由記述や社内機密データを扱う案件と同じ手順で運用し、その検証を兼ねるため。

境界は「**生の発言と話者を出さない**」に置く。

| 対象 | 例 |
|---|---|
| APIの生レスポンス | 発言本文・発言者名を含むJSON |
| 個票の抜き出し | クラスタの代表発言を人手で確認するために抽出したテキスト |
| 不具合調査の証跡 | 事象再現時のレスポンス実物、詳細ログ |
| その他、公開判断がつかないもの | **迷ったらここへ置く** |

## 配置

```
private/
└── issues/
    └── ISSUE-NNN-{slug}/     不具合調査の非公開証跡
```

## docs/ 側との対応

`docs/issues/ISSUE-NNN-{slug}/issue.md` の「証跡」節に、ここへのパスと各ファイルの内容を記載する。
**ファイルの中身を `docs/` 側へ転記しない。** 公開可能な形（エラーメッセージ、件数、本文を除いた構造）に加工したものだけを `issue.md` 本文に書く。
発言本文と発言者名は書かない。`speechID` は伏せる。

## 注意

- **このディレクトリの内容は他の環境に存在しない。** `issue.md` は証跡が無くても調査を再開できるだけの情報を本文に持たせること
- 認証情報はここではなく `.env` / 環境変数で扱う（`CLAUDE.md` 4章）
