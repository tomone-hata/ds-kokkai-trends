## 本リストの出所

**候補A〜Dは依頼者の発言によるものではなく、担当（Claude）が提示した案である。** `[推測]`

経緯は次のとおり（[ヒアリング記録](hearing-2026-08-18.md) 4節 Q-010）。

1. 依頼者から「客観的な指標から選びたいが、何かよい案はあるか」との質問があった `[事実]`
2. 担当が候補A〜Dを提示し、Aを主軸・Bを補完とする案を推奨した
3. 依頼者は「AとBどちらもPoCで使ってみるのがよい。ここもPoCの論点でよい」と判断した `[事実]`

**したがって情報源の選定根拠は担当の判断であり、検証の対象である。** 本文書はその根拠と実在確認の結果を記録する。

## 候補の一覧と採否

| ID | 情報源 | 採否 | 選定・不採用の理由 |
|---|---|---|---|
| **A** | 施政方針演説・所信表明演説の項目 | **採用** | 年ごとに発行され項目立てされている。政権の政策アジェンダを網羅する。**年次で変化するため、固定リストよりトレンド分析の評価に適合する** |
| **B** | 提出議案リスト | **採用** | 実際に審議された立法事項を網羅する。**会議録に含まれない外部情報**であり、内容の面でも独立している |
| C | NDL「調査と情報—ISSUE BRIEF」 | 不採用 | 国会図書館が議員向けに作成する調査資料で、論点性の高いものが選別されている。**ただし発行が不定期で年次の対応付けが煩雑**なため、PoCでは見送る |
| D | 報道の年間回顧・重大ニュース | 不採用 | **媒体の編集方針が入り客観性が限定的**。国会外の話題も混在し、フィルタが必要 |

**A と B は性質が異なるため併用する。** Aは政権の重点、Bは立法事項をカバーし、**どちらにも対応しないクラスタが「発見候補」となる**（要件定義書 5.2.1節）。

## 実在確認の結果（2026-08-19）

### 参照A: 施政方針演説・所信表明演説

| 項目 | 確認結果 |
|---|---|
| 出典 | 首相官邸ホームページ `https://www.kantei.go.jp/` |
| **掲載範囲の制約** | **現職および過去3代までの内閣のみ。** それ以前は国立国会図書館「インターネット資料収集保存事業（WARP）」でアーカイブされている |
| 見出し構造 | **存在する。** 第1レベルと第2レベルの階層を持つ |

**2025年に該当する演説（PoC対象年）**

| 演説 | 日付 | 国会回次 | URL |
|---|---|---|---|
| 石破内閣総理大臣 施政方針演説 | 2025-01-24 | 第217回 | `https://www.kantei.go.jp/jp/103/statement/2025/0124shiseihoshin.html` |
| 高市内閣総理大臣 所信表明演説 | 2025-10-24 | 第219回 | `https://www.kantei.go.jp/jp/104/statement/2025/1024shoshinhyomei.html` |

**第217回国会 施政方針演説の第1レベル見出し（8項目）**

1. 国づくりの基本軸
2. 地方創生2.0、「令和の日本列島改造」の具体化
3. 経済・財政・社会保障
4. 防災・治安
5. 外交・安全保障
6. 政治改革
7. 憲法改正等
8. 結語

**設計上の含意**

- PoC設計書 Q-015 の粒度規則「見出し階層の第1レベル1項目＝1論点」は**実データで成立する**
- 第2レベル見出しも存在するため、粒度を細かくする余地がある
- **「結語」のような論点でない見出しが含まれる。** 粒度規則で除外対象として扱う必要がある
- **本番対象期間（2019〜2025年）では、古い年の演説が WARP 依存になる可能性が高い。** 期間中に5代の内閣（安倍・菅・岸田・石破・高市）が存在するため、官邸サイトの掲載範囲を超える。取得可否を年ごとに確認すること

### 参照B: 提出議案リスト

| 項目 | 確認結果 |
|---|---|
| 出典（衆議院） | `https://www.shugiin.go.jp/internet/itdb_gian.nsf/html/gian/menu.htm`（回次ごとの議案一覧） |
| 出典（参議院） | `https://www.sangiin.go.jp/japanese/joho1/kousei/gian/{回次}/gian.htm` |
| 構造 | 議案は区分（**閣法**＝内閣提出／**衆法**＝衆議院議員提出等）と番号を持ち、件名が付されている |

**第217回国会（2025-01-24〜2025-06-22、常会）の議案例**

- 閣法 第1号 所得税法等の一部を改正する法律案
- 閣法 第25号 特別会計に関する法律の一部を改正する法律案
- 閣法 第29号 人工知能関連技術の研究開発及び活用の推進に関する法律案
- 衆法 第21号 政治資金規正法及び租税特別措置法の一部を改正する法律案
- 衆法 第64号 民法の一部を改正する法律案

**設計上の含意**

- PoC設計書 Q-015 の粒度規則「議案1件＝1論点」は成立する
- 議案番号が採番されているため、**同一性の判定と件数の確定が機械的に行える**
- 閣法の番号が29号以上あることから、**1回次あたりの議案は数十件規模**と見込まれる。参照Aの8項目より1桁多く、**粒度が細かい**
- 衆議院・参議院の双方に提出議案があるため、**重複の扱いを定める必要がある**（同一議案が両院を通過するため）
