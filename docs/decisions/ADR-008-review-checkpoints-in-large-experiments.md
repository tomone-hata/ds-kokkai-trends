# ADR-008: 多段の実験では、不可逆な決定の直後に experiment-analyst の検証を挟む

## 1. 背景

### 現行規約の想定

`.claude/rules/experiment-code.md` は次のように定めていた。

> **実験の終了時**
> 結果が出たら `experiment-analyst` エージェントに検証を依頼する。**自分で「良い結果が出た」と結論づけない。**

**この文言は、1回の実行で完結する小さな実験を前提としている。** 実験が終わってから検証すればよいのは、途中に不可逆な決定が無い場合に限られる。

### 実際の実験はそうなっていない

EXP-001（論点抽出ベースライン）は **11ステージ・想定17.0〜18.0人日**の多段実験であり、**段階的な貪欲決定**で構成されている。

| ステージ | 決定内容 | 工数 |
|---|---|---|
| S-3 | 分かち書き手法の決定 | 1.5日 |
| S-4 | 前処理水準（E-0 / E-1 / E-2）の確定。**分析単位 U-1・k=100 を暫定固定して比較する** | 1日 |
| S-5 | 分析単位（U-1 / U-2）の確定。**S-4 で確定した水準の下で比較する** | 1.5日 |
| S-6 | ベクトル化 × クラスタリングの構成実行 | 3日 |
| S-7 | 主観評価（SE-B）により**構成を1つに確定する** | 1.5日 |

**先行するステージの決定が、後続ステージの比較の前提になる。** S-4 の判断を誤っても、S-5 以降はその誤った水準を前提として比較を続けるため、**誤りが矛盾として表面化しない。**

### 既存のチェックポイントでは防げない

PoC設計書は CP-1・CP-2・CP-3 を定めているが、**いずれも撤退判定である。**

| | 何を守るか | 判定方法 |
|---|---|---|
| CP-1（S-1完了時） | 収集が成立しないまま進むこと | D-1a / D-1b / D-1c の数値閾値 |
| CP-2（S-6 X-1完了時） | 退化した構成で走り続けること | D-2 / D-3 の数値閾値 |
| CP-3（S-6完了時） | 全構成が脱落した状態で進むこと | D-2e / D-3d の数値閾値 |

**これらは「無駄に走り続けること」を防ぐが、「誤った前提のまま走り続けること」は防がない。**

**そして不可逆な決定を含む S-4・S-5・S-7 には、チェックポイントが1つも無い。**

### 実際に自己判断で結論づけた事例が出た

S-1（データ収集）の完了時、担当（アシスタント）は検証を依頼せず、次の解釈を自ら確定させた。

| 主張 | 性質 |
|---|---|
| D-1（収集の成立性）は成立した | CP-1 の機械的判定に基づく |
| 2025年1月のみの標本は年全体の文字数分布を代表していなかった（中央値 196 対 318） | **解釈** |
| 短文が大量に存在するという想定は成立しなかった（10文字以下は0.01%） | **解釈** |

**後2つは前処理の除外閾値（S-4）の根拠になる。** 現行規約の文言では「実験の終了時」まで検証が入らないため、この解釈は S-11 まで独立の検証を受けない。

## 2. 決定

**多段の実験では、実験の終了時だけでなく、不可逆な決定を含むステージの直後に `experiment-analyst` による検証を挟む。** 検証を通過するまで次のステージへ進まない。

**各レビューポイントで問う内容は、実験の実施前に固定する。** 固定していない観点をその場で追加しない。

## 3. 検討した選択肢

| 案 | 内容 | 採否 |
|---|---|---|
| A | **不可逆な決定の直後にレビューポイントを置く。問う内容は事前に固定する** | **採用** |
| B | 現行どおり実験の終了時のみ検証する | 不採用 |
| C | 実験の単位を小さく切り、1実験1決定にする | 不採用 |
| D | 全ステージの完了時に検証する | 不採用 |

## 4. 判断根拠

1. **誤決定は下流で検出できない。** 段階的な貪欲決定では、先行する決定が後続の比較の前提になる。S-4 の水準を誤って確定しても、S-5 は「その水準の下で U-1 と U-2 のどちらが良いか」を比較するだけであり、水準そのものの誤りは問われない。**検出の機会は決定の直後にしか無い。**

2. **手戻りのコストが決定の位置で決まる。** S-5 完了時点で誤りが見つかれば失うのは S-3〜S-5 の 4.0人日だが、S-11 で見つかれば実験全体の 17.0〜18.0人日を失う。**S-6（3日）が最も重いステージであり、その手前に検証を置く価値が最も高い。**

3. **主観評価は自己採点になりうる。** S-7 は SE-B（主観評価）により構成を確定する。**自分が出した主観評価を自分で採否判断すると、独立性が構造的に確保できない。** 盲検化はシルエット値に限定されており（PoC設計書 5章）、評価者の判断そのものは盲検化されない。

4. **実験の単位を小さくしても解決しない**（案C を退ける根拠）。単位を分割しても貪欲に決める構造は変わらず、分割された実験の間で同じ伝播が起きる。**問題は実験の大きさではなく、決定の不可逆性である。**

5. **初回の実験はベンチマークが存在しない。** 過去の実験と比較して異常を検知することができないため、**その場での妥当性検証以外に誤りを捕まえる手段が無い。**

## 5. 採用しなかった案を退けた理由

### 案B（現行どおり実験の終了時のみ）

**規約の文言としては現行のままでも読めるが、多段実験では検証が実質的に機能しない。**

S-11 の時点で S-4 の決定が誤っていたと判明しても、**その時点では既に S-5〜S-10 がその前提の上に積み上がっている。** 検証は「やり直すべきか」の判断にしか使えず、**予防にならない。**

### 案C（実験の単位を小さく切る）

**原則としては正しく、一般には推奨される。** 1実験1決定にすれば、実験の終了時＝決定の直後となり、現行規約のままで機能する。

**しかし本件では成立しない。** PoC の目的は「教師なし学習で論点が抽出できるか」の成立性検証であり、**収集だけ、前処理だけを切り出しても何も判定できない。** 「データが取れた」は成立性の証拠にならない。**最低でも収集からクラスタリング・命名までを通さなければ、仮説 H-002〜H-007 のいずれも検証できない。**

**したがって PoC の単位が大きくなることは、この目的においては避けられない。** 案A はその制約を受け入れた上での対策である。

**ただしこれは初回に限る。** 2回目以降は初回の結果がベンチマークになるため、単位を小さく切れる余地が生まれる（7節）。

### 案D（全ステージの完了時）

**レビューが結論の追認になる。**

11ステージすべてに検証を置くと、判断を伴わないステージ（実行のみのステージなど）でも形式的な確認が発生する。**「妥当だと思います」で通す回数が増えるほど、レビュー全体が儀式化し、本当に見るべき箇所での緊張が失われる。**

コストも無視できない。**検証の回数ではなく、置く位置が重要である。**

## 6. 想定される結果

| 良い影響 | 悪い影響・受け入れるコスト |
|---|---|
| 誤決定が下流へ伝播する前に検出できる | レビュー4回分の時間が増える |
| 手戻りが最大でも直前のレビューポイントまでに限定される | ステージ間で待ちが発生する |
| 主観評価の採否に独立した目が入る | 問う内容を事前に固定する手間が生じる |
| 自己判断で結論づける事象が構造的に起きにくくなる | レビューが差し戻しを出した場合、想定工数を超える |

## 7. 見直す条件

以下のいずれかに該当したとき、本決定を再検討する。

1. **EXP-001 が完了し、2回目以降の実験に着手する段階に入ったとき。** 初回の結果がベンチマークとして機能するようになれば、案C（実験の単位を小さく切る）が成立する余地が生まれる。その時点で本決定の必要性を再評価する
2. **レビューポイントでの差し戻しが0回のまま EXP-001 が完了したとき。** 4回すべてが通過するだけであれば、レビューが機能していないか、そもそも不要であった可能性がある。**通過率と、レビューによって実際に変更された判断の件数を `report.md` に記録すること**
3. **レビューによる待ち時間が、実験全体の工数の20%（3.4〜3.6人日相当）を超えたとき**

### EXP-001 における配置（設計書改訂時の入力）

本決定を EXP-001 に適用した場合の配置を、設計書改訂の入力として記録する。

| RP | 位置 | 問う内容（事前に固定する） |
|---|---|---|
| RP-A | **S-2 完了時** | データが分析に足るか。文字数分布・短文割合の解釈が S-4 の除外閾値の根拠として妥当か |
| RP-B | **S-5 完了時** | S-3・S-4・S-5 の3つの決定が、比較設計として成立しているか |
| RP-C | **S-7 完了時** | 盲検化の手順が守られたか。9.4節の決定規則が主観に引きずられていないか |
| RP-D | S-11 | 実験全体の結論。現行規約の「実験の終了時」に相当する |

**S-4 に単独の RP を置かない。** S-4（1日）と S-5（1.5日）は隣接して短く、S-6（3日）の手前で1度止めれば手戻りの抑制には足りるため。

**S-1 完了時に RP を置かない。** S-1 で得た解釈（文字数分布・短文割合）は S-2 の検証対象そのものであり、RP-A でまとめて検証すれば足りる。CP-1 は機械的判定として既に通過している。
