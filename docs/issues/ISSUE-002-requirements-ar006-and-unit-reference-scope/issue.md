## 1. 事象

PoC設計書のレビューにより、要件定義書 v2.0 に2件の欠陥が指摘された。いずれも**設計書側では処理済みだが、上流の記述が残ったままである**ため、将来の実装者が誤読する。

### 1.1 AR-006 の受入条件が判定不能である

**観測された結果**: AR-006 の受入条件は「PoC対象期間についてクラスタごとの推移が**表示できること**」であるが、同書 8.1節は「Streamlit は PoC設計の確定後に依存へ追加する」と定めている。

**期待した結果**: 受入条件は、PoCの完了時点で判定可能であること。

**何が問題か**: **PoC 内でダッシュボードを実装しないのであれば、何をもって「表示できること」を満たすのかが定まらない。** v2.0 では 8.3節を新設して「Jupyter での表示をもって充足し、ダッシュボード実装は PoC スコープ外」と記述したが、**AR-006 の受入条件欄そのものは変更していない。** 同一文書内で受入条件と充足方法が別々に記述され、対応が明示されていない。

### 1.2 分析単位と参照リストの観測範囲が広すぎる

**観測された結果**: 2.3.1節に「**単位と参照リストの組み合わせで一致率を観測する**」と記述されている。

**何が問題か**: この記述をそのまま実装すると、**採用しなかった単位についても一致率を算出する**ことになる。算出すれば「一致率が高い方を採ればよかった」という事後の再選択を誘発し、`.claude/rules/experiment-code.md` 禁止事項4（評価データを手法選択に用いない）に抵触する経路が開く。

PoC設計書 6.3A.5節は「**採用した単位についてのみ観測する**」に限定しているが、**上流の記述が現状のままだと、将来の実装者が両単位での算出を要求と読む。**

**再現手順**: 要件定義書 v2.0 の AR-006 受入条件欄と 8.1節・8.3節を対照する。および 2.3.1節末尾と PoC設計書 6.3A.5節を対照する。

再現性: 常に再現（文書の記述である）

## 2. 調査ログ

### 2026-08-19

- **確認したこと**: PoC設計書 v0.9 のレビュー結果（7章 #1・#2）を受け、要件定義書 v2.0 の該当箇所を確認した
- **結果**: 2件とも指摘のとおりであることを確認した
- **1.1 について**: v2.0 で 8.3節を追加した際、**AR-006 の受入条件欄を更新しなかった**。8.3節を読まなければ受入条件の充足方法が分からない状態になっている
- **1.2 について**: 2.3.1節の当該記述はこちらが v2.0 で追加したものである。**追加時点では `experiment-code.md` 禁止事項4 との関係を検討していなかった**
- **この時点での判断**: 1.1 は依頼者の判断を要する（受入条件を変えるか、判定を先送りするか）。1.2 は設計書側の限定が正しく、上流を追随させるべき
- **依頼者の判断（同日）**: 1.1 は **(a) AR-006 の受入条件を「Jupyter 等での表示で充足」と明記する**

## 3. 原因

| # | 原因 |
|---|---|
| 1.1 | v2.0 の改訂で 8.3節を新設した際、**同じ事柄を述べる AR-006 の受入条件欄へ波及させなかった。** 節を追加して他の参照箇所を更新しない「部分適用」であり、[ISSUE-001](../ISSUE-001-requirements-analysis-unit-and-review-conditions/issue.md) 6章が指摘した欠陥と同型である |
| 1.2 | 2.3.1節を執筆した時点で、**下流の規約（`experiment-code.md` 禁止事項4）との整合を確認しなかった。** 要件の記述が下流の禁止事項に抵触しうるという観点が抜けていた |

## 4. 対策

| 項目 | 内容 |
|---|---|
| 選択した対策 | **設計変更を伴う。** 要件定義書 v2.0 → v2.1 |
| 恒久対策か暫定対応か | 恒久対策 |

### 4.1 AR-006 の受入条件（依頼者の判断: 案(a)）

受入条件を「**Jupyter 等での表示をもって充足する**」と明記し、8.3節への参照を付す。

**受入条件は判定可能でなければ機能しない。** 「表示できること」の手段が未定のままだと、EXP-001 の S-10 の完了判定で解釈が割れる。

### 4.2 2.3.1節の観測範囲

「単位と参照リストの組み合わせで一致率を観測する」を「**採用した単位についてのみ観測する**」に限定し、理由（`experiment-code.md` 禁止事項4）を併記する。

## 6. 再発防止

**節を追加したら、同じ事柄を述べる他の箇所を検索して波及させる。** [ISSUE-001](../ISSUE-001-requirements-analysis-unit-and-review-conditions/issue.md) 6章の再発防止（引用先が主張を支持しているかの確認）に加え、**「追加した記述と矛盾または重複する既存記述がないか」を用語で全文検索する**ことを改訂手続きに含める。

本件および PoC設計書 v0.8 の適用漏れ（[再レビュー](../../reviews/レビュー_PoC設計書-論点抽出_v0.9_20260819.md) J-001〜J-003）は、いずれも**部分適用**という同一の失敗様式である。

**要件の記述が下流の規約に抵触しないかを確認する。** 1.2 は「要件としては自然だが、実験規約の禁止事項に触れる」という形の欠陥であった。要件定義の時点で `.claude/rules/experiment-code.md` の禁止事項と突き合わせる。
