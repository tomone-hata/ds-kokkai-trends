## 1. 事象

3回目レビューが「当該ステージ到達までに解消」とした条件のうち、**S-5・S-6 到達前に必要な3件**である。

### 1.1 構成確定ステージが実験計画に存在しない（J-006 / 条件D-1）

**観測された結果**: 9.4節が構成（ベクトル化 × クラスタリング）の決定規則を定めているが、**12.1節のどのステージでもこの決定が行われない。** S-9（命名）・S-10（時系列集計）の前提が **S-6** となっている。

**期待した結果**: どのステージで構成が確定するかが実験計画から読み取れること。

**何が問題か**: S-6 は「X-1〜X-5（+X-6）を実行する」ステージであり、**構成の採否を決める工程がない。** S-9・S-10 は単一の構成に対して行うはずだが、前提が S-6 のままだと**複数構成のどれを使うのかが不定**になる。9.4節の決定規則は SE-B（S-7 で実施）を用いるため、**構成の確定は S-7 でしか行えない。**

### 1.2 決定規則が用いる主観評価が特定されていない（J-010 / 条件D-2）

**観測された結果**: 9.4節 規則2 が「**解釈可能率（5.2節）**が最も高い構成を採用する」と記述している。

**何が問題か**: 5.2節には **SE-A（水準比較用）と SE-B（構成横断）の2種類**があり、どちらを指すかが特定されていない。**SE-A は S-3〜S-5 で暫定固定値の下に実施されるものであり、構成の選定には使えない。** 正しくは SE-B である。

特定されていないと、実装者が SE-A を用いる余地が残る。SE-A は水準ごとに20件、SE-B は構成ごとに40件で、**評価対象も件数も異なる。**

### 1.3 D-3 の扱いが2箇所で矛盾する（J-018）

**観測された結果**:

| 箇所 | 記述 |
|---|---|
| 2.4節 | S-3〜S-5 における D-3 は「**判定しない。記録のみ**」 |
| 6.3A.4節 規則1 | 「**D-3（退化）に該当する単位を除外する**」（S-5 の決定規則） |

**何が問題か**: **S-5 は「判定しない」範囲に含まれるが、その決定規則は D-3 の条件を判定に用いている。** 実装者はどちらに従うべきか判断できない。

**再現手順**: 設計書 2.4節「S-3・S-4・S-5 で撤退判定を行わない理由」の表と、6.3A.4節 規則1 を対照する。

再現性: 常に再現（文書の記述である）

## 2. 調査ログ

**追記のみ。否定された仮説も消さない。**

### 2026-08-20

- **確認したこと**: 3回目レビュー 8.2節 D-1・D-2 と 20.2節 J-018 の該当箇所を設計書 v1.0 で確認した
- **結果**: 3件とも指摘のとおりであることを確認した
- **1.3 の性質について**: 当初これを「用語の不統一」と捉えたが、**実質は「撤退判定」と「選定のための判定」の混同**である。D-3 の条件式を**撤退の判断に使う**のと、**候補を絞る判断に使う**のは別の行為であり、2.4節が禁じているのは前者だけである。6.3A.4節 規則1 は後者であり、矛盾ではなく**書き分けの不足**であった
- **否定した選択肢**: 6.3A.4節 規則1 から D-3 への言及を削る案は採らなかった。**退化した単位を選定候補に残す方が有害**であるため。2.4節側に書き分けを追加する方向で解消する

## 3. 原因

| # | 原因 |
|---|---|
| 1.1 | v0.8 でステージ順序を再設計した際、**9.4節（構成の決定規則）を 12.1節のステージへ割り当てなかった。** 決定規則の存在と、それを実行するステージの対応が取られていない |
| 1.2 | v0.8 で主観評価を SE-A / SE-B に分離した際、**9.4節の「解釈可能率（5.2節）」という既存の記述を更新しなかった。** 分離前は1種類しかなかったため特定が不要だった |
| 1.3 | 2.4節が「D-3 を判定しない」と書いた際、**その「判定」が撤退判定を指すことを明示しなかった。** 選定のための判定と区別していない |

1.1・1.2 はいずれも**部分適用**であり、[ISSUE-001](../ISSUE-001-requirements-analysis-unit-and-review-conditions/issue.md) 6章・[ISSUE-002](../ISSUE-002-requirements-ar006-and-unit-reference-scope/issue.md) 6章が指摘した失敗様式と同型である。

## 6. 再発防止

**決定規則を定めたら、それを実行するステージを実験計画に割り当てる。** 1.1 は「規則はあるが実行者がいない」という形の欠落であり、規則単体を読んでも検出できない。**9章〜11章の各決定規則について、12.1節に対応するステージが存在するかを対照する**ことを改訂手続きに含める。

**用語を分離したら、分離前の語を使っている箇所をすべて特定する。** 1.2 は SE-A / SE-B への分離時に「解釈可能率」という上位語が残った例である。[ISSUE-002](../ISSUE-002-requirements-ar006-and-unit-reference-scope/issue.md) 6章の再発防止（追加した記述と矛盾・重複する既存記述を用語で全文検索する）を、**「分離した場合は上位語の全出現を洗う」まで拡張する。**

**禁止を書くときは、禁止の対象を限定する。** 1.3 は「判定しない」が広すぎたことによる。**何を禁じ、何は許すのかを同じ場所に書く。**
