## 判定理由

**数値そのものに誤りは検出されなかった。** `config.md` に記載された指標・評点は、`outputs/` の現行ファイルおよび `private/` の評価記録から再計算して一致した。語彙サイズは記録された条件のみから独立に再現できた（4方式と U-1 で完全一致）。**S-3〜S-5 を再実行する必要はなく、選ばれた3水準（W-2・E-2・U-1）を差し替える必要もない。**

差し戻しの理由は、**記録が「何が確立されたか」を過大に述べており、その過大な前提の上に S-6 以降が積み上がること**にある。3点が該当する。

1. **S-4 の SE-A は設計書 5.2.1節の盲検化手順に反して実施された。** 同節は「当該ステージで比較する全水準分をまとめてシャッフルして提示する」と定めるが、3水準のうち E-0 は S-3 のバッチで評価済みの値を流用し、S-4 では2水準しか混ぜていない。`config.md` はこれを「厳密な盲検ではない」という**限界**として記録しているが、これは限界ではなく**手順からの逸脱**である。しかも回避手段（同一シードで抽出済みの E-0 の20件を S-4 のバッチへ再提示する）は存在した。`config.md` が回避しない理由として挙げる「抽出シードが42に固定されているため逸脱にあたる」は成立しない。シードが定めるのは**どのクラスタを抽出するか**であって、提示回数ではない。
2. **S-3・S-4 の決定根拠である SE-A の差は、SE-A の分解能を下回る。** S-3 は 7/20 対 5/20（Fisher 正確検定 p=0.73）、S-4 は 10/20 対 7/20（p=0.52）である。真の解釈可能率が等しくても、20件の抽出で2件以上の差がつく確率は約0.30ある。**決定規則1 に従った点で手続きは正しいが、「W-2 が最も高い」「E-2 が明確に高い」という記述は測定が支持していない。** 現状の記録のままでは、S-6 以降が「優位性が示された水準」を前提として進む。
3. **S-5 の U-1 / U-2 比較は交絡している。** 担当は「ハードコード値は3ステージで共通固定だから比較は成立する」と述べるが、`min_df=5`・`max_df=0.5` は**文書数と文書長に依存する閾値**であり、文書数が100倍・文書長が100倍異なる2単位に同じ値を与えることは同じ条件を与えることではない。実測すると `max_df=0.5` は U-1 で8語（延べトークンの 19.45%）を除去するのに対し、**U-2 では564語（延べトークンの 68.12%）を除去している。** U-2 側は延べの3分の2を失った特徴空間でクラスタリングされた。

**解消はすべて記録の訂正・追記と ISSUE 起票で完結し、再実行を要しない**（(g) 節）。想定 0.5人日以下であり、S-6（3日）の手前で止める手戻りとして小さい。

## (c) S-3（分かち書き）は比較設計として成立しているか

**手続きは設計書どおりである。** 4方式を同一条件（E-0・U-1・k=100・シード42）で走らせ、SE-A 80件を1バッチでシャッフルして評価し、7.4節 規則1 で W-2 を選んでいる。比較条件・ハードコード値・辞書の版はすべて `config.md` に記録されている。**本検証は記録された条件のみから4方式の語彙サイズを完全に再現できた**（27,544 / 20,674 / 113,065 / 495,729）。**再現情報としては十分である。**

成立を損なう点が2つある。

### C-1. 首位の差（7 対 5）は SE-A の分解能を下回る

| 比較 | 評点2の件数 | Fisher 正確検定 p | Jeffreys 95%区間 |
|---|---|---|---|
| W-2 対 W-1 | 7/20 対 5/20 | **0.73** | 17.2〜56.8% 対 10.2〜46.4% |
| W-2 対 W-3 | 7/20 対 4/20 | 0.48 | 17.2〜56.8% 対 7.2〜40.8% |
| W-2 対 W-4 | 7/20 対 2/20 | 0.13 | 17.2〜56.8% 対 2.1〜28.4% |

**4方式のいずれの対比較も有意ではない。** 真の解釈可能率が全方式で等しい（例: 30%）場合でも、20件の抽出で片方が2件以上上回る確率は 0.30、3件以上上回る確率は 0.19 ある。**つまり「W-2 が首位」という観測は、方式間に差が無くても3回に1回程度起きる。**

抽出は100クラスタからの20件であるため有限母集団修正が効くが、補正係数は 0.90 でありこの結論は変わらない。**加えて SE-A には反復測定が無い**（設計書が再判定を求めるのは S-8 の参照突合のみである）。したがって評価者内のゆらぎは測定されておらず、上記の区間は**下限の不確実性**である。

**担当が記録した LLM 2種による参考評価は、この不安定性の直接の証拠になっている。** LLM-A は W-1・W-2・W-3 の同率首位、LLM-B は W-1 首位であり、**評価者を替えると順位が入れ替わる。** `config.md` はこれを「LLM は判定が甘い」と絶対値の差として説明しているが、問題は絶対値ではなく**順位が評価者依存であること**である。

**これは担当の逸脱ではない。** 設計書 5.2.1節が SE-A の件数を20件と定め、7.4節が点推定の大小のみで決める規則を置いている。**設計そのものが、識別しようとする差を識別できない標本設計になっている。** ただし `config.md` の「解釈可能率が最も高い方式により**単独首位**」という記述は、測定が支持する以上のことを述べている。

### C-2. 盲検化は W-3・W-4 に対して機能していない

設計書 5.2.1節は方式名を伏せてシャッフルすることを求めるが、**提示される特徴語トップ20 そのものが方式を明かす。**

| 方式 | 提示item の特徴語の平均文字数（最小 / 中央 / 最大） |
|---|---|
| W-1 モードC | 1.50 / 2.25 / 2.95 |
| W-2 モードA | 1.85 / 2.08 / 2.70 |
| W-3 文字2-gram | **2.00 / 2.00 / 2.00** |
| W-4 文字3-gram | **3.00 / 3.00 / 3.00** |

**n-gram 系40件は、特徴語がすべて2文字ちょうど・3文字ちょうどで構成されるため、統計を用いずに識別できる。** 評価者は設計者本人であり「文字n-gram は辞書不要だが語として読めない」という事前の予期を持つ。**脱落した2方式については、盲検化は名目上のものであった。**

一方、**実際に競った W-1 と W-2 は分布が重なっており、識別は容易でない。** 首位の決定に対する影響は限定的である。この非対称も記録に無い。

## (d) S-4（前処理水準）は比較設計として成立しているか

### D-1. 盲検化手順からの逸脱（差し戻しの主因）

設計書 5.2.1節の盲検化の定義は次のとおりである。

> 水準名・方式名を伏せ、**当該ステージで比較する全水準分をまとめてシャッフルして提示する**

S-4 が比較する水準は E-0・E-1・E-2 の3つであるが、**まとめてシャッフルしたのは E-1・E-2 の2水準40件のみ**であり、E-0 の20件は S-3 のバッチ（4方式80件）で評価された値をそのまま用いている。**これは手順からの逸脱である。**

`config.md` はこれを「厳密な盲検ではない」という**限界**として記録し、「再サンプリングすれば解消できるが、設計書は抽出シードを42に固定しており逸脱にあたる」ことを理由に回避していない。**この理由付けは成立しない。**

- シード42 が定めるのは**どのクラスタを20件抽出するか**である。E-0 の20件を再抽出する必要はなく、**同じ20件を E-1・E-2 と混ぜて60件として提示すれば、シードを動かさずに 5.2.1節を満たせた。**
- すなわち、**逸脱を避ける手段は存在し、コストは20件の再評価だった。**

**影響の評価。** 決定への影響は小さいと考えられるが、**それは E-0 の値に依存しない経路で決着しているためである。**

| 対比較 | 提示条件 | 決定への寄与 |
|---|---|---|
| E-2（10/20）対 E-1（7/20） | **同一バッチ・相互に盲検** | 首位の決定はこの対比較で完結する |
| E-2 対 E-0（7/20） | 別バッチ・別日・提示文脈が異なる | 首位の決定には不要 |

さらに、**文脈効果の向きは E-0 に有利に働いた可能性が高い。** E-0 の20件は S-3 のバッチで、内容語を持たない n-gram 系40件と混在して評価された。相対的に読みやすい item は高く評価されやすい。**それでも E-0 は 35.0% であり、E-2 の 50.0% を下回っている。**

**したがって「E-2 を採る」という結論は維持してよい。** 訂正すべきは、これを「限界」と呼んでいる記録の方である。**現時点では評価者が既に全80件・全40件を見ているため、再評価による回復はできない。** 記録として残す以外の解消手段は無い。

### D-2. 首位の差（10 対 7）も分解能を下回る

| 比較 | 評点2の件数 | Fisher 正確検定 p | Jeffreys 95%区間 |
|---|---|---|---|
| E-2 対 E-1 | 10/20 対 7/20 | **0.52** | 29.3〜70.7% 対 17.2〜56.8% |
| E-2 対 E-0 | 10/20 対 7/20 | 0.52 | 同上 |

`config.md` の「**解釈可能率は E-2 が明確に高い**（50.0% 対 35.0%）」「E-1 と E-2 の差はわずか 2,560件（2.18%）だが、**15ポイントの改善を生む**」という記述は、**3件の差を因果として述べており、測定が支持していない。** 15ポイントという表現は、20件の標本では1件が5ポイントに相当することを踏まえて読む必要がある。

### D-3. 決定に用いていない補強材料が存在する（記録の位置づけの問題）

担当は「決定規則1 は解釈可能率のみで決めるため、事後に別の指標を持ち出さない」として、次を観測事実に留めている。**この判断は正しい**（事後の基準追加は 5節の禁止に触れる）。ただし S-6 以降へ引き渡す際の重みづけには関わる。

| 材料 | E-0 | E-1 | E-2 |
|---|---|---|---|
| ゼロベクトル件数 | 67 | 10 | **1** |
| 最小クラスタサイズ | 59 | 103 | **156** |
| ジニ係数（M-4） | 0.4661 | 0.4124 | **0.4035** |
| 最大クラスタ占有率（M-3） | 7.33% | **6.96%** | 8.42%（悪化） |

**E-2 は主観評価以外の3指標でも E-1 以上であり、悪化するのは M-3 のみである。** SE-A 単独では E-2 の優位を示せないが、**独立な複数の指標が同じ向きを指している事実は、決定の頑健性を補強する材料として `report.md` に書ける**（決定規則に組み入れるのではなく、決定の不確実性の評価として）。

## (e) S-5（分析単位）は比較設計として成立しているか

**結論から述べる。S-5 は「単位の比較」としては成立していない。** 実施された内容は「U-2 は k=100 の下で D-3b に該当する」という判定であり、比較の主指標である SE-A には到達していない。**採用結果（U-1）自体は妥当であり、差し替えを要しない。**

### E-1. 判定結果は S-5 の実行前に確定していた

D-3b は「クラスタ数 ÷ 対象件数 > 5%」である。U-2 の対象件数は会議数であり、**会議数 1,126 は S-1 の完了時点で判明していた**（`config.md` S-1 節・S-2 節、および `s2_quality/summary.json` の `distinct_issue_id`: 1126）。したがって `100 ÷ 1,126 = 8.881% > 5%` は、**S-5 を実行せずとも算術的に確定していた。**

**S-5 の 1.5人日は、既知の値から導ける結論の確認に費やされている。** これは担当の落ち度というより設計の欠陥である。設計書 6.3A節の想定件数は「**数千規模**（未実測。S-5 で確定）」であり、数千であれば k=100 でも平均サイズ 20〜60 となり D-3b に触れない。**実測が想定より1桁小さかったために、6.3A.3節（k=100 固定）と 6.3A.4節 規則1（D-3 該当を除外）の組合せが、比較の前に単位を落とす構造になった。**

なお設計書 6.3A.3節は「k=100 のとき U-2 は**数十件規模**となる」とも書いており、**この予測値自体が D-3b の閾値（平均サイズ20）を跨いでいる。** 設計時に両者の突き合わせが行われていれば、S-5 の前に検出できた。（**RP-A でも検出していない。** RP-A の問いは S-2 のデータ品質に固定されており、本件は範囲外であった。）

### E-2. D-3b は単位固有の性質ではなく、単位と k の組合せを判定している

| k | U-1（111,426件） | U-2（1,126件） |
|---|---|---|
| 20 | 0.018%（平均 5,571.3） | 1.776%（平均 56.3） |
| 50 | 0.045%（平均 2,228.5） | 4.440%（平均 22.5） |
| **100** | 0.090%（平均 1,114.3） | **8.881%（平均 11.3）→ 該当** |
| 200 | 0.179%（平均 557.1） | 17.762%（平均 5.6）→ 該当 |

**k ≤ 50 であれば U-2 は D-3b に該当しない。** 担当の自己申告（「D-3 が単位固有の性質ではなく k との組み合わせを判定していないか」）は**そのとおりである**。`config.md` はこの限界を明記しており、「k を調整して再判定しない」という判断も 6.3A.3節（交絡回避のため1構成に限定）に照らして正しい。

ただし D-3b の**実質的な根拠**（2.3節: 月次12点に分割すると1点あたり1〜2件となる）は U-2 に実際に当てはまる。1クラスタ平均 11.3会議・中央値8会議では、月次の比率推移は描けない。**「規則が形式的に発火しただけ」ではなく、可視化の入力にならないという判定の中身は正しい。**

### E-3. ハードコード値が2単位に同じ条件を与えていない（未記録の交絡）

担当は「4つのハードコード値は3ステージで共通固定であり、共通固定であれば比較は成立するか」と問うている。**S-3・S-4 についてはおおむね成立するが、S-5 については成立しない。** `min_df` と `max_df` は文書数・文書長に依存する閾値であり、単位を変えると意味が変わるためである。

**実測（本検証で再現。正規化 → W-2 分かち書き → E-2 適用後）**

| | U-1 発言単位 | U-2 会議単位 |
|---|---|---|
| 文書数 | 111,426 | 1,126 |
| 延べトークン | 12,109,856 | 12,109,856（同一） |
| 異なり語 | 45,172 | 45,172（同一） |
| `min_df=5` の相対閾値 | 0.0045% | **0.4440%**（約100倍厳しい） |
| `min_df=5` による除去 | 24,499語（延べの 0.41%） | 26,325語（延べの 0.57%） |
| **`max_df=0.5` による除去** | **8語（延べの 19.45%）** | **564語（延べの 68.12%）** |
| 採用語彙 | 20,665 | 18,283（実測 18,321） |

**U-2 は延べトークンの 68% を失った特徴空間でクラスタリングされている。** U-1 で残る語のうち 556語が U-2 では `max_df` により消えている。**「同じ値を入れたから同じ条件」ではない。** 会議単位テキストは1件あたり中央値 38,764字あり、ほとんどの一般語が半数超の会議に出現するため、`max_df=0.5` がストップワード除去ではなく内容語の除去として作用している。

**この交絡は S-5 の決定を変えない**（D-3b は特徴空間に依存しない）。しかし `config.md` の「U-2 の脱落は k=100 に起因する。単位ごとに k を最適化すれば結論が変わりうる」という申し送りは**不十分である。** k を変えても、`min_df` / `max_df` を文書集団に応じて定義し直さない限り、U-2 の再評価は同じ交絡を抱える。
