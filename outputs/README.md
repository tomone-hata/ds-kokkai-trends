# outputs/

実験・分析の出力置き場。**このREADME以外はGit管理外。**

## 置くもの

| 対象 | 例 |
|---|---|
| 実験の全出力 | クラスタ割り当て、埋め込みベクトル、評価指標のダンプ |
| 図表の生成物 | 描画した全ての図（採用・不採用を問わず） |
| 中間集計 | 集計途中のParquet、キャッシュ |

## 配置

実験IDごとにディレクトリを分ける。**`docs/experiments/` および `experiments/` と同じディレクトリ名を使う。**

```
outputs/
└── EXP-NNN-{slug}/
```

## docs/ との使い分け

- ここには**全出力**を吐く。再生成可能な成果物であり、サイズが大きいためGitに載せない
- **レポートに採用した図のみ** `docs/experiments/EXP-NNN-{slug}/figures/` へコピーする（GitHub上でレポートを図付きで読めるようにするため）
- **図に発言本文を焼き込まない。** ラベルには特徴語・クラスタIDを使う
