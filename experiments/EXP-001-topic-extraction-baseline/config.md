**設計書の逸脱にあたらない**と判定された。6.2節は 3-2 を1回しか規定していないが、(1) 新しい処理を追加しておらず 3-3 が壊した不変条件を回復しているだけ、(2) 3-2 は冪等であり差が生じるのは間に 3-3 が入る場合のみ、(3) 3-3 のパターンに前後の空白を吸収させれば 3-2 一回と同結果になる等価な実装が節内に存在する、が根拠である。

**影響量**: 5,537件・平均1.06字・最大17字。≤10 が 3,447 → 3,454（+7）、≤20 が 6,009 → 6,014（+5）。**T1 = 10 / T2 = 20 は不変。**

**5,537件は角括弧ト書きの出現件数と一致する。** 再適用が後始末以外の働きをしていないことの傍証である。

**本実装への申し送り**: 6.2節の表だけを読むと再適用が落ちる。

### 平均削減量が 12.46 → 15.53 に増えた理由

**主因は 3-2 である。** NFKC 未適用時の実装は DuckDB（RE2）の `\s` を使っており、**RE2 の `\s` は U+3000 に一致しない。** NFKC を先に置いて初めて全角空白が 3-2 の対象になった。**修正の副産物ではなく修正の効果である。**

工程別の削減量（平均 / 最大）: NFKC −0.03 / 3-2 5.98・2,190 / 話者表記 8.79・21 / 角括弧 0.62・68 / 丸括弧 0.13・54 / 3-2再適用 0.05・17。**いずれも上限がパターンの設計上限と整合する。**
